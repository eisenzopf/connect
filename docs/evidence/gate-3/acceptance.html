Keep the limits and failed attempts visible.

  • Local macOS arm64 only. Chrome uses loopback host/host UDP ICE; telephone tests use the recorded Telnyx registration/NAT path and owned receivers. WAN/TURN, mobile devices, arbitrary carriers and audio hardware are not qualified.
  • Model context has a 32 KiB item budget. Older sources remain in authorized history with explicit omission counts; automatic summaries and pinned-fact retrieval are future decisions.
  • The three required spoken decisions were recalled exactly after restart. A supplemental written-code assertion returned courts harbor instead of Quartz Harbor, following a phonetic telephone transcript. The original draft and transcript remain separate sources.
  • The first inbound attempt after a long idle/sleep period failed before answer. Fresh registration and a later idle-period retest succeeded; the original cause remains unproven.
  • Live SMS remains deferred pending carrier approval. MCP/skill, another assistant, task resumption, video and the complete v0.1 release remain assigned to later gates.
Preserved unsuccessful trials and fixes
  • Earlier provider chat input strategies rejected or ignored history; corrected prompt-variable path qualified.
  • Initial browser signaling race/cleanup and restricted route credential failures were fixed and retested.
  • Initial inbound before fresh registration and the earlier handset 603 rejection remain failures.
  • Early telephone receiver interruption and third-answer truncation are not three-turn passes; the tuned bounded receiver passed.
  • Two large provider HTTP reads failed before remote-end submission; explicit cleanup and a documented filtered read produced a passed installed-client remote-end test.
  • Concurrent Gate 2 debug init exceeded its deadline; isolated unchanged-source regression passed.
  • The supplemental exact written-code spelling assertion remains failed; all three required voice decisions passed.
  • The first documentation-bundle build encountered an existing-directory collision before creating archives. A corrected clean revision built and passed all 10 installed checks.

Current source retains the original records. Failed supplemental assertions are separate from the required criterion results; they are not relabeled as passes. Memory selection and source precedence remain a product decision before expanding context tools.

The ownership boundary

Rudeless PostgreSQL

The original form evidence remains immutable: mobile number, requested task, explicit consent, exact disclosure/version, source and server timestamp. Additive migration 0005 stores reviewer, activation, expiry and revocation. An unchecked checkbox cannot be approved.

Connect SQLite

Schema 10 retains authenticated enrollment evidence, authority revision and freshness, keyword events, suppression state and delivery decisions. Every SMS delivery from every public interface uses the same outbox check.

Telnyx

Signed callbacks update Connect. Provider-classified STOP/START/HELP phrases and literal keywords never become assistant prompts. Provider acknowledgements must match the approved campaign; Connect does not send duplicate replies.

Enrollment → activation → delivery

  1. The recipient submits their own SMS form. A request without SMS consent remains valid but cannot authorize texting.
  2. An administrator reviews the recipient and requested task. Activation binds one form record to a sender number, Connect conversation and expiry of at most 30 days. Review uses the existing authenticated session plus CSRF protection.
  3. Connect fetches the installation-scoped feed using a separate read-only service bearer. Neither agents nor public form submissions can mint grants.
  4. Before each provider dispatch, Connect checks the recipient/sender/conversation, grant expiry, authority freshness and suppression state. Missing authority fails closed.
  5. STOP persists and cancels pending sends. START/UNSTOP only remove suppression for a previously enrolled recipient; task approval and freshness still apply. Replaying a cancelled logical message does not resend it.

A new form or refreshed grant cannot clear STOP. HELP changes no permission. Delayed START cannot overtake a newer STOP; STOP wins equal timestamps.

Explicit timing and recovery limits

  • The worker refreshes enrollment every 30 seconds when available. A successful snapshot has a 90-second lease. An unreachable authority therefore cannot authorize indefinitely.
  • Revocations take effect on the next successful refresh; during an outage, the previous lease expires within 90 seconds. Startup clears leases and requires a fresh snapshot.
  • STOP takes effect when its authenticated callback commits locally. A request already claimed and in flight cannot be recalled. Telnyx suppression is an additional provider boundary.
  • Grant evidence is immutable; revisions reject stale or inconsistent snapshots. Provider event IDs deduplicate callbacks. Backups include every new table and delivery decision.
  • The retained installation was stopped, backed up and explicitly migrated from schema 9 to 10. Existing identities, credentials, conversations, messages and routes were verified unchanged before adding the SMS route.

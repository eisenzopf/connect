Native wire proof

Two independent physical QUIC peers authenticate, bind the same durable Session through namespaced canonical IDs, offer one PCMU stream each, subscribe to the other publisher and exchange audio in both directions. The first best-effort media packet may precede the reliable subscriber-stream announcement; the receiver registers the announced peer-local stream and subsequent packets flow. This is normal datagram loss behavior, so applications must not treat the first RTP packet as a control acknowledgement.

Local cross-transport proof

The SIP test admits a configured route, carries PCMU both ways through the pinned rvoip SIP adapter and ends only the bounded Session. The WebRTC test authenticates its retained signaling lease, negotiates Opus, uses rvoip's Opus↔PCMU media graph for the Vapi boundary, carries audio both ways and imports the final transcript into the same Conversation. Neither test claims public-network or provider reachability.

Local operating envelope

  • Target: one and four concurrent two-party sessions for at least 60 seconds.
  • Target: p95 server forwarding contribution at or below 50 ms, excluding provider/model and playout time.
  • Target: queued audio at or below 200 ms; paired teardown within five seconds.
  • Network rehearsal: 3% loss and up to 100 ms delay variation without crash, runaway queues or stuck teardown.

The operating profile uses ten 20 ms frames as each local audio queue's ceiling. Connect explicitly configures rvoip orchestration, native QUIC streams and the Vapi adapter with this limit. The opt-in upstream interfaces are preserved in a source-locked patch; upstream defaults remain compatible. This is a buffering limit, not a claim that total network, model and playout latency is 200 ms.

The completed audit qualifies real reordered RTP, unknown-stream rejection, saturation with provider queue measurements, credential expiry and bounded cancellation/peer-loss recovery. One- and four-Session 60-second profiles run with deterministic source loss, delay variation and concurrent reliable artifact traffic. Changed-profile qualification is in progress; provider and human audible checks remain separate live evidence.

Build with Connect / Start

Start with messages and retained history.

Choose a published runtime or the current development source before following its commands.

Install the published local package

The published v0.1 package targets macOS arm64. Follow installation and checksum verification, then select the extracted executable. Read its release exceptions and prerequisites.

These instructions describe that published API generation. They do not install a Gate 6 SDK candidate or configure a remote server.

Exchange a message and reply

The published provider-free demo starts its own local server, exchanges messages and files through the native public client, restarts, and verifies retained history. Use a fresh writable directory:

CONNECT=/absolute/path/to/extracted-runtime/bin/connect
"$CONNECT" --version
"$CONNECT" setup demo --directory ./connect-demo --bind 127.0.0.1:0

Expect a JSON result for the deterministic demo. This is simulated local participation, not an actual model or provider call. The matching setup guide explains state permissions, failures and recovery. Existing state must not be overwritten.

The clean installed Gate 6 first-conversation quickstart is still planned in G6-082. Its commands and timing have not been qualified by this documentation structure change.

Work with the current source

Use signed initialization and serving, the typed Rust SDK and explicit application configuration. Native and HTTP configurations are distinct; neither silently selects a fallback.

The review-loop initialization preset currently enrolls communication identities; the earlier review-loop app still awaits its signed SDK migration. Follow the workspace build/check guide for development, rather than running the published demo against an unrelated source binary.

Continue with your app

Learn the model, then explore voice and video or the Parley progression. Media readiness requires actual decoded media; a command ACK or an answered call alone does not prove it.

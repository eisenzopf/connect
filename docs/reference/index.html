Source guides and generated contracts

These links share one versioned navigation map. Generated OpenAPI and SDK target contracts describe their named interface; they do not imply installed package parity, complete browser media qualification or an HTTP live-media channel.

Voice and video

Start with media profiles, native media and browser control/media. Capability detection, permission, negotiation and decoded media are distinct. MCP/JSON CLI control output contains no audio frames.

The development browser WT/WSS/WebRTC tasks remain open. Retained native private-audio and browser audio failures remain unresolved; later passing diagnostics do not erase them. See the current private-audio finding and current plan. Published v0.1 media has its own release scope and exceptions.

Consultation, handoff and device movement

Use private consultation, handoff, transition contracts and telephone replacement. Keep the retained remote leg and original operation identity; recover uncertainty through current-authorized status.

Handoff changes responsibility and audience. Device movement replaces a Participant's leg. Invitation acceptance is not business consent, and a candidate answer does not replace the configured confirmation or actual media checks.

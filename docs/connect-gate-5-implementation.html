The scope stays attached to the product.

The Gate 5 product plan and A5-01–A5-16 acceptance map define the outcome. This checklist preserves G5-A–G5-E and every F-01–F-21 commitment from the roadmap.

Conversation first

One durable history.

Video, voice, messages and files share the existing Conversation. Bounded sessions, provider legs and tasks do not reset context. Keep provenance, omissions and explicit developer-created boundaries.

Agent access

One revocable identity.

Keep optional task tracking and narrow grants without making them mandatory. No per-action approval console. Retained owner diagnostics survive revoking the agent key; later actions still require current authority.

Execution boundary

Local and reproducible.

Use isolated databases, local provider fixtures and explicit host selection. No new public ingress, provider account mutations, calls/SMS or remote deployment are part of automatic checks.

Gate 4 runtime 709cf82, qualification d64f1b9 and documentation c00de2c remain source-scoped baseline evidence. The Gate 4 report does not qualify changed Gate 5 behavior. Native QUIC remains central; a browser or provider transport is described as its actual transport.

Build in parallel where the contracts allow it.

M0 freezes the contracts and baseline. Video, connector/protocol and setup work can then proceed in parallel at their listed dependencies. Integrate the public journeys before final packaging and independent review.

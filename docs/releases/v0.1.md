# Connect v0.1

Connect v0.1 provides a local communications server and SDKs for people, applications and agents. **Runtime version 0.1.0; macOS arm64.**

- Durable conversations, messages, files and revocable identities.
- Rust, Python and TypeScript interfaces, MCP agent access, and public-interface examples.
- Two-party VP8/PCMU video over native QUIC and browser WebRTC.
- Provider-free setup, protected secrets, contact pairing and connector/conformance kits.

### Download and run

Download the runtime archive plus `SHA256SUMS`. The matching source and historical recovery archives are separate assets. Run `shasum -a256 -c SHA256SUMS` after downloading all three archives. Extract the runtime, select its absolute `bin/connect` path, and follow its README. The provider-free `setup demo` needs no model or provider account.

The qualification supplement has its own `SUPPLEMENT_SHA256SUMS` file.

See `connect-v0.1-qualification-supplement.tar.gz` for the exact results and exception record. No raw failed result or test threshold was changed to make it pass.

### Scope

One simultaneous two-party call is the supported design profile. Browsers use WebRTC; native clients use QUIC. FFmpeg, Chrome, Node, Playwright and independent Python tooling are external prerequisites. Generated media does not prove physical-device permissions or arbitrary NAT/TURN reachability.

No multiparty video, screen sharing, SIP/PSTN video, Vapi vision, automatic model wake, additional-platform qualification or remote deployment is promised. Publication performs no live calls, SMS or provider account changes.

# Connect v0.1

First public release for **local macOS arm64**. Connect provides a communications
server, public Rust/Python/TypeScript interfaces, MCP agent access, examples and
an independent UCTP control client.

- Durable conversations, messages, files and revocable identities.
- Optional task tracking and explicit saved-session continuation for Codex.
- Two-party VP8/PCMU video across native/native, native/browser and browser/browser;
  native transport is QUIC and browser media is WebRTC.
- Provider-free local setup, protected secret references, contact pairing,
  connector templates and conformance fixtures.

## Distribution and verification

GitHub release destination: `eisenzopf/connect`, tag `v0.1`.
The public release uses version **0.1.0**. Its archives are rebuilt on the current
Mac because the earlier approved `284cef1` alpha archives remain on another
computer. These new files must have their own checksums and package qualification;
the earlier archive hashes are not reused.

The release assets comprise the macOS arm64 runtime, matching complete source,
historical recovery fixtures, checksums and qualification/evidence supplement.
Verify the downloaded assets against `SHA256SUMS` before extraction. The runtime
contains `bin/connect`, `bin/connect-example` and `bin/connect-video`, SDKs,
reference client, contracts and guides. Select the installed `bin/connect`
absolute path and follow its bundled local setup instructions.

## Limits

One simultaneous two-party VP8/PCMU call is the supported video profile.
Impaired A/V quality is advisory only under Decision 012; clean/mute and all
non-A/V hard checks remain strict. No multiparty, screen-sharing, SIP/PSTN video,
Vapi vision, automatic model wake or additional-platform qualification is implied.
FFmpeg, Chrome, Node, Playwright and the independent Python environment are
external prerequisites. Generated-media tests do not establish physical-device
permissions or arbitrary NAT/TURN reachability.

Model and provider evidence keeps its original execution/source scope. No fresh
carrier/Vapi operation or remote-server deployment is part of publication.
Usability and quality completion were confirmed by the owner; detailed human
timings and final reviewer findings were not supplied with those confirmations.

Publication status and exact new candidate evidence will be recorded after build,
package checks and independent release download verification succeed.

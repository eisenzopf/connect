Build with Connect / Hosting

Start locally. Verify each boundary.

A healthy HTTP endpoint, an enrolled contact and usable telephone media are different observations.

Current local setup

  • Published macOS arm64 runtime: matching package setup, release limits and private state.
  • Current source initialization: enrolled signed clients, explicit listener addresses and protected configuration.
  • HTTP configuration and authorization: application/protected boundaries, files and operation recovery.
  • Trusted provisioning: keep administration and provider secrets on the backend.

Remote hosting and providers

Ubuntu 24.04 x86_64, public TLS/HTTP3/WSS, ICE/TURN and named provider profiles are Gate 6 targets. Their complete installation and deployment qualification remains open. A local pass is not a remote hosting result.

The operating profile defines those targets and bounds. The executable operator guide is G6-086 work after hosting, trust and package prerequisites. Named model/provider rehearsals require their configured endpoints and execution authority.
